🛠️ ΑΝ ΚΑΤΙ ΧΑΛΑΣΕΙ (τα σημερινά μαθήματα)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1) Health fail / "connected": false
   - SUPABASE_URL πρέπει να είναι το σωστό project
     (π.χ. https://xxxxx.supabase.co) — χωρίς typo
   - SUPABASE_SERVICE_ROLE_KEY = sb_secret_...
     (ΟΧΙ eyJ... legacy JWT αν τα legacy keys είναι off)
   - Μετά:
        npm run env:push-netlify
        npx netlify deploy --prod
   - Ξανα:
        curl -s https://voyaflair.com/api/health/

2) Resend "API key is invalid"
   - Νέο key από resend.com/api-keys → .env → env:push-netlify → deploy

3) Resend "domain is not verified"
   - resend.com/domains → add voyaflair.com
   - Netlify DNS (NS1) → TXT @ =
        resend-domain-verification=...
   - Έλεγχος:
        dig TXT voyaflair.com +short
   - Όταν φαίνεται το record → Verify στο Resend → ξανά send

4) Unauthorized στο newsletter
   - Το Bearer πρέπει να ταιριάζει με NEWSLETTER_ADMIN_SECRET
     στο Netlify (ίδιο με .env μετά από env:push-netlify + deploy)
